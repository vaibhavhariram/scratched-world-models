# Archive

Historical snapshots. **Nothing here is a current claim about the project.**

These documents predate the naming and scope rules in `CLAUDE.md` and the phase structure in
`ROADMAP.md`. They are retained unedited, as evidence of what was found and decided at the time.
`CLAUDE.md` requires recording what was actually observed; editing these to match current rules
would destroy exactly that record.

So they contain terms the current rules prohibit. In `CONTEXT_RECOVERY.md` those appear
diagnostically — cataloguing the three coexisting project names and asking where the branch prefix
came from — rather than as assertions about the project. That is the same category as the
prohibition lists in `CLAUDE.md` and `ROADMAP.md`, which necessarily quote the terms they ban.

For current scope and claims, read `ROADMAP.md`. For working rules, read `CLAUDE.md`.
